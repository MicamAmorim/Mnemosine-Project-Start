# Assets

Imagens e identidade visual do projeto (cartas, retratos, locais, instrumentos, motivos, horários, rotas, logo e textura de papel).
O gerador lê estes arquivos diretamente (`../04_Assets/...`); em `https://` não é preciso nenhuma cópia local.

Para impressão profissional, prefira versões em **≥ 1000 px** no lado menor: as imagens quadradas de 506×506 px são suficientes
para a carta em 300 DPI (52 × 38 mm), mas não para ampliações.
